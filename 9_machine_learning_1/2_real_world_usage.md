# Machine Learning

## Real-World Examples

- **YouTube Recommendations** → Learns from your watch history
- **Spam Detection in Gmail** → Learns patterns in spam emails
- **Voice Assistants (Siri, Alexa)** → Learn how you speak
- **Self-driving Cars** → Learn to identify stop signs, pedestrians, and roads
- **Face Unlock on Phones** → Learns to recognize your face

---

## What is Machine Learning?

**Machine Learning (ML)** is a subset of Artificial Intelligence (AI) that enables systems to automatically learn and improve from experience without being explicitly programmed.

Instead of following fixed rules, ML algorithms use data to find patterns, make decisions, and predict outcomes.

### Key Concept: Learning from Data

At its core, machine learning works like this:

1. **Input Data** → Provide examples (e.g., emails, images, videos)
2. **Training** → The algorithm finds patterns in the data
3. **Model** → A mathematical representation of those patterns
4. **Prediction** → The model makes decisions on new, unseen data

### Types of Machine Learning

- **Supervised Learning** — Learning with labeled data (e.g., spam vs. not spam)
- **Unsupervised Learning** — Finding hidden patterns in unlabeled data
- **Reinforcement Learning** — Learning through trial and error (rewards/punishments)

### Why It Matters

Machine Learning powers many of the technologies we use daily — from personalized recommendations to voice recognition and autonomous vehicles. It turns data into intelligence, making systems smarter and more adaptive over time.
