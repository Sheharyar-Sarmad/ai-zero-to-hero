# Introduction to Git

## What This Covers
Git basics: tracking changes, saving snapshots, and collaborating.

## Why Version Control
- Undo mistakes
- See what changed and when
- Work with others without overwriting files

## Learning Workflow
1. Create a repo
2. Edit files
3. Stage changes
4. Commit

```bash
git init
git add .
git commit -m "First commit"
git status
```
