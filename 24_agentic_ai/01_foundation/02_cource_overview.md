# 🚀 Course Overview

Welcome to the Agentic AI Crash Course! In this comprehensive guide, we will learn how to build production-grade AI agents using LangGraph. We will move beyond simple prompting and explore how to orchestrate complex, autonomous systems.

Instead of just theory, we will take a hands-on approach, mastering the core workflows that power modern AI agents. By the end of this course, you will be able to create your own multi-agent systems, RAG-powered chatbots, and human-in-the-loop applications.

## 🧠 Core Concepts We Will Learn
We will dive deep into the internals of LangGraph to understand how agents actually work under the hood. You will learn about:
- 🧩 **State & Nodes**: Managing the data and logic in your agent.
- 🔀 **Edges & Conditional Edges**: Controlling the flow of execution.
- ⚡ **Reducers & Parallelism**: Handling fan-out/fan-in workflows efficiently.
- 💾 **Checkpointing**: Adding memory and persistence to your graphs.
- ✋ **Interrupts & Human-in-the-Loop (HITL)**: Building agents that pause for human approval.
- 🌊 **Streaming & Subgraphs**: Creating responsive and modular agent architectures.
- 🛡️ **Error Handling**: Building robust agents that can recover from failures.
- 🧭 **When to Use LangGraph**: Understanding its advantages over simpler `create_agent` functions.

## 🛠️ Projects We Will Build
We will learn by building real, practical projects. I haven't decided on the exact projects yet, but whatever we create will surely be production-ready and help you prepare for real-world jobs. You will gain hands-on experience with every core workflow type.

## 🎯 The 5 Core Workflow Types
Throughout this course, we will master the 5 workflow types that power every modern AI agent:
1. ➡️ **Sequential**: Step-by-step execution where one node follows another.
2. ⚡ **Parallel**: Fan-out and fan-in execution for handling multiple tasks simultaneously.
3. 🚦 **Conditional**: Routing execution based on specific logic or state (e.g., RAG).
4. 🔄 **Iterative**: Self-reviewing and looping workflows to improve output over time.
5. 👤 **Human-in-the-Loop**: Pausing the agent's execution for human intervention.
