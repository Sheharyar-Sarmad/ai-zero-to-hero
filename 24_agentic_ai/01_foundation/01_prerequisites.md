# 🛠️ Prerequisites

Before diving into Agentic AI, please ensure you have the following baseline knowledge. These concepts are essential before we begin.

- ✅ **Completed <a href="https://github.com/Sheharyar-Sarmad/ai-zero-to-hero" target="_blank">ai-zero-to-hero</a> Repo Till Now**: If you have completed this repository with me, that is exceptional! You are more than ready.
- 🐍 **Python (Intermediate)**: You must be comfortable with APIs, OOP, async, and data structures. This is not a course for simple Python basics.
- 🤖 **AI & GenAI**: Foundational understanding of generative AI concepts.
- 🧠 **LLMs & Transformers**: Basic conceptual knowledge of how they work and are used.
- 📊 **ML & DL**: Basic machine learning and deep learning concepts (training, inference, neural networks).
- ⚙️ **Tools & Agents**: A foundational understanding of tools, agents, loops, Human-in-the-Loop (HITL), external data fetching, state, memory, context, prompting, and agent decision-making is required. This is not a beginner-level agentic AI course; it is an intermediate-level course. You should already be familiar with agentic AI architecture. We will be focusing on learning workflows using LangGraph. For learning agentic AI & its architecture from scratch, visit the <a href="https://github.com/Sheharyar-Sarmad/ai-zero-to-hero/tree/main/23_genai_3" target="_blank">ai-zero-to-hero/23_genai_3</a> Repo.
