

# Introduction to Linux

## What is Linux?

**Linux** is an open-source operating system kernel that is widely used in:

- Software development
- Cloud computing
- DevOps
- Servers
- Cybersecurity
- AI/ML
- System administration

Linux provides a powerful **command-line environment** that allows developers to interact directly with the operating system.

### Popular Linux Distributions

Some popular Linux distributions are:

- Ubuntu
- Debian
- Fedora
- Arch Linux
- Linux Mint
- Kali Linux

---

# Why Learn Linux?

Linux is very important for software engineers and AI engineers because many:

- Production servers
- Cloud servers
- Docker containers
- AI/ML environments
- Web servers
- DevOps systems

run on Linux.

Learning Linux also helps developers understand how operating systems, files, processes, permissions, networking, and servers work.

---

# Ubuntu

**Ubuntu** is one of the most popular Linux distributions.

It is based on **Debian** and is beginner-friendly.

Ubuntu is commonly used for:

- Software development
- Web development
- AI/ML development
- Cloud computing
- Servers
- DevOps

# My Linux Setup

> **Important:** I am **not installing Linux as my primary/core operating system.**

I am currently using **Windows** as my main operating system and installing **Ubuntu inside Windows** for learning and development.

I am using **WSL (Windows Subsystem for Linux)** to run Ubuntu.

My setup looks like this:

Windows
   |
   └── WSL
        |
        └── Ubuntu
             |
