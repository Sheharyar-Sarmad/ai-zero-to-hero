# Prerequisites

Before starting RAG, make sure you're comfortable with these — all covered in earlier modules.

## Required Knowledge

| Topic | Module |
|---|---|
| Python (functions, OOP, file I/O, async) | 01, 02 |
| Package management (`uv`, `pip`, `.env`) | 03 |
| LangChain basics (chains, prompts, runnables) | 02, 21 |
| Embeddings & cosine similarity | 03, 20 |
| NLP basics (tokenization, chunking) | 16 |
| FastAPI (routes, Pydantic, uploads) | 15 |
| Next.js + React basics | 21 |
| Linux / shell / git | 14 |

## Required Tools

- Python 3.12+
- `uv` or `pip`
- Groq API key — [console.groq.com](https://console.groq.com/) (free)
- Hugging Face account — [huggingface.co](https://huggingface.co/) (free)
- VS Code (or similar) + terminal

## Quick Self-Test

You're ready if you can:

- [ ] Write a Python script from scratch
- [ ] Build a basic LangChain chain with Groq
- [ ] Generate embeddings using HuggingFace
- [ ] Create a FastAPI route with a Pydantic model
- [ ] Deploy a Next.js app on Vercel

## Not Needed

- Deep learning math (backprop, gradients)
- Training your own models
- Vector DB internals (HNSW, IVF)
- Kubernetes / Docker

## If Anything Feels Weak

Go back and review that module for 2–3 days before starting RAG. It'll save you hours of confusion later.
