# Model Tuning & Hyperparameter Tuning

---

## 1. Model Tuning

**Definition:**  
Model tuning is the process of improving a machine learning model's performance by adjusting its configuration and training settings.

### Includes

- Hyperparameter tuning
- Feature selection
- Feature engineering
- Algorithm selection
- Regularization
- Threshold tuning
- Class weighting

---

## 2. Parameter

**Definition:**  
A parameter is a value that the model learns automatically from training data.

### Examples

- Weights
- Bias
- Regression coefficients
- Tree split values

---

## 3. Hyperparameter

**Definition:**  
A hyperparameter is a value set before/during training that controls how the model learns.

### Examples

- `max_depth`
- `n_estimators`
- `learning_rate`
- `C`
- `gamma`
- `n_neighbors`

---

## 4. Hyperparameter Tuning

**Definition:**  
Hyperparameter tuning is the process of finding the best hyperparameter values for a model.
