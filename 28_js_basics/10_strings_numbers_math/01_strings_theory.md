# Strings & Built-in String Methods

Strings are used for storing and manipulating text. They are immutable sequences of characters.

## Key String Properties and Methods
1. **Length:** `str.length` returns the number of characters.
2. **Finding & Extracting:**
   - `indexOf(substring)`: Returns the index of the first occurrence.
   - `includes(substring)`: Returns `true` or `false`.
   - `slice(start, end)`: Extracts a section of a string.
3. **Modification & Transformation:**
   - `toLowerCase()` / `toUpperCase()`: Changes case.
   - `trim()`: Removes whitespace from both ends.
   - `replace(target, replacement)`: Replaces matching text.
   - `split(separator)`: Splits a string into an array of substrings.
