# Numbers & The Math Object

## 1. Number Methods & Properties
- `toFixed(digits)`: Formats a number using fixed-point notation (returns a string).
- `Number.isInteger(value)`: Checks if a value is an integer.
- `parseFloat()` / `parseInt()`: Parsing string numbers.

## 2. The Built-in `Math` Object
Unlike objects you create, `Math` is a static built-in object providing mathematical constants and functions.
- `Math.round(x)`: Rounds to the nearest integer.
- `Math.floor(x)` / `Math.ceil(x)`: Rounds down / up.
- `Math.max(...nums)` / `Math.min(...nums)`: Finds max/min values.
- `Math.random()`: Returns a pseudo-random number between `0` (inclusive) and `1` (exclusive).
