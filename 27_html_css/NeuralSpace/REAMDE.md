
# 🌌 NeuralSpace

NeuralSpace is a modern, dark-themed AI SaaS landing page built using HTML5 and CSS3. This project demonstrates essential frontend development concepts through a responsive, visually appealing interface.

# Live Demo

[NeuralSpace](https://neural-space.netlify.app)

## ✨ Features
- Dark theme with glowing cyan accents
- Responsive design for desktop, tablet, and mobile
- Animated elements and interactive hover effects
- Hero, features, pricing, and testimonials sections
- Modern styling with smooth transitions

## 🧠 Concepts Used
- **HTML5:** Semantic elements, page structure, navigation, links, and buttons
- **CSS Selectors:** Element, class, and pseudo-class selectors
- **Flexbox & Grid:** Layouts, alignment, and content positioning
- **Responsive Design:** Media queries and mobile-friendly layouts
- **CSS Animations:** Keyframes, transitions, transforms, and hover effects
- **Visual Styling:** Gradients, shadows, borders, and glowing effects
- **Typography:** Font sizes, weights, line height, and text hierarchy
- **CSS Variables:** Reusable colors and consistent design values

## 🛠️ Technologies
- HTML5
- CSS3

## 🚀 Getting Started
1. Clone or download the repository.
2. Open `index.html` in your browser.
3. Resize the browser to explore the responsive layout.
