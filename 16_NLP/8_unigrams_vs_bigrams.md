

# Unigram vs Bigram

## Unigram

- A **unigram** is a single word/token.
- Captures individual words but little context.

**Example:**

```text
"I love machine learning"
→ I, love, machine, learning
```

# Bigram

A bigram is a pair of consecutive words/tokens.
Captures more local context than a unigram.

# Example:

"I love machine learning"
→ I love, love machine, machine learning

# Difference

# Unigram Bigram

1 word	2 consecutive words
Less context	More context
Fewer features	More features
learning	machine learning

# Memory Trick

Unigram → 1 word
Bigram → 2 words
